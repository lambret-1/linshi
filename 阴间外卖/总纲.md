| 正文定稿 | `第[三位章号]章_定稿.md` | `第001章_定稿.md` |

| 日志文件 | `[日志类型]日志.md` | `修订日志.md` |
| 归档文件夹 | `v[版本号]_归档_[YYYYMMDD]/` | `v1.0_归档_20260101/` |
| 风格样章 | `样章[两位序号]_[风格标签].md` | `样章01_冷冽风.md` |
| 修订版本 | `_v[主版本].[次版本]` | `_v1.1`（小修）/ `_v2.0`（大改） |

### 3.4 命名注意事项

- **编号补零**：纲体系编号两位补零（00-99），卷号两位补零（01-50），章号三位补零（001-2000）
- **版本号统一**：所有文件使用`vX.Y`格式，不使用V/v混用
- **禁止空格**：文件名中使用下划线`_`连接，不使用空格或特殊字符
- **后缀统一**：所有文档使用`.md`后缀
- **日期格式**：归档日期使用`YYYYMMDD`八位数字，无分隔符
- **全局中文**：除版本号`v`和文件后缀`.md`外，全部使用中文命名

```markdown
## 一、五纲调度规则

### 1.1 调用关系图

```
01-主线纲.md（P0）
  ├──→ 02-卷纲.md（P1）
  │      └──→ 04-章纲/第XX卷_第XXX-XXX章.md（P3）
  ├──→ 05-人物纲.md（P1）
  │      └──→ 04-章纲/第XX卷_第XXX-XXX章.md（P3）
  └──→ 03-支线纲.md（P2）
         └──→ 04-章纲/第XX卷_第XXX-XXX章.md（P3）
```

> **核心原则**：上游纲约束下游纲，下游纲不得反向修改上游纲。所有修改必须自上而下级联。

### 1.2 级联更新规则表

| 修改源 | 直接影响 | 间接影响 | 更新操作 |
| :--- | :--- | :--- | :--- |
| 01-主线纲.md | 02-卷纲.md、05-人物纲.md、03-支线纲.md | 04-章纲/ | 重审所有下游纲的阶段目标/情绪曲线/角色弧光 |
| 02-卷纲.md | 04-章纲/ | 03-支线纲.md嵌入点 | 重拆受影响单元的章纲任务 |
| 05-人物纲.md | 04-章纲/ | 03-支线纲.md关系线 | 更新受影响章节的角色任务/对话/身体描写 |
| 03-支线纲.md | 04-章纲/ | 无 | 更新受影响章节的支线标注/字数占比 |
| 04-章纲/ | 无 | 无 | 仅更新本章，不回溯上游 |

### 1.3 优先级裁定表（P0-P4）

| 优先级 | 来源 | 裁定规则 | 典型冲突场景 |
| :--- | :--- | :--- | :--- |
| **P0** | 01-主线纲.md·核心冲突/结局走向 | 不可违背，任何下游纲与之冲突时必须让步 | 02-卷纲.md节奏与主线阶段目标矛盾 |
| **P1** | 01-主线纲.md·角色认知档案 / 05-人物纲.md·S级设定 | 角色行为必须符合当前认知层级，情节为角色服务 | 04-章纲任务要求角色做出不符合认知的选择 |
| **P2** | 02-卷纲.md·情绪曲线 / 03-支线纲.md·自驱目标 | 情绪节奏优先于单章爽点；支线独立性优先于主线便利 | 04-章纲爽点破坏卷级情绪铺垫 |
| **P3** | 04-章纲·钩子/埋点配置 | 钩子类型/位置/绑定关系在章级锁定 | 正文写作时发现更好的钩子方案 |
| **P4** | 正文·语言/细节/节奏微调 | 在不违反P0-P3前提下自由发挥 | 正文发现更自然的对话表达 |

### 1.4 跨纲一致性校验机制

| 触发时机 | 检查内容 | 发现问题处理 |
| :--- | :--- | :--- |
| 每完成一卷04-章纲 | 章纲任务是否覆盖02-卷纲所有目标；角色行为是否符合05-人物纲当前状态；支线嵌入是否符合03-支线纲活跃度矩阵 | 回溯修正章纲，记录偏差原因至修订日志.md |
| 每完成一个阶段（50章） | S级角色认知变化是否与01-主线纲节点对齐；埋点回收率是否达标（查埋点追踪表.md）；钩子类型分布是否均衡 | 批量修正并更新进度追踪表.md |
| 每次修改上游纲后 | 所有受影响的下游纲是否已同步更新 | 按§1.2级联更新规则表逐项执行，未完成前禁止继续创作 |
| 正文写作中发现偏差 | 正文是否偏离04-章纲P0-P3约束 | 记录偏差至修订日志.md→评估是否需要回溯修改章纲→更新版本 |
| 每10卷深度审查 | 五纲整体是否仍自洽；是否有累积性偏移 | 全面审查+00-总纲.md更新 |
```

## 五、总纲自维护规则

### 5.1 更新触发条件

| 触发条件 | 更新内容 | 紧急度 |

| 外部反馈揭示体系缺陷 | 对应模块修订 + 修订日志.md记录 | 评估后决定 |

### 5.2 总纲与五纲的同步机制

- **单向约束**：00-总纲.md约束五纲的管理方式，但不干预五纲的内容创作
- **同步方向**：五纲内容变更 → 触发00-总纲.md审查 → 00-总纲.md决定是否更新
- **禁止反向**：00-总纲.md不得直接修改五纲内容；如需修改，必须通过五纲自身的修订流程

### 5.3 版本管理

| 版本类型 | 格式 | 触发条件 | 示例 |
| :--- | :--- | :--- | :--- |
| 主版本 | vX.0 | 结构性变更（新增纲层级/工作流重构/目录结构大改） | v1.0 → v2.0 |
| 次版本 | vX.Y | 内容修订（规则调整/清单更新/命名规范微调） | v1.0 → v1.1 |
| 补丁版本 | vX.Y.Z | 勘误/笔误修正 | v1.1 → v1.1.1 |
