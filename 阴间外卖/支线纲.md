# 《超时扣款，阴间催单》完整支线纲体系

## 一、10条核心支线详细设定

### S1：林晚调查线——"真相的代价"

- **核心命题**：追求真相是否值得以摧毁现有秩序为代价？
- **自驱目标**：查明妹妹林曦离奇死亡与"阴阳闪送"系统的关联，收集可公开的系统害人医学证据
- **关键角色**：林晚、医院档案室老张、记者周然
- **与主线交叉点**：
  - 第3卷：作为"活人订单"触发者登场，提供妹妹治疗资源
  - 第7卷：识破系统伪装，成为陈默"人间锚点"
  - 第13卷：证据被毁，陷入绝望
  - 第15卷：绝望倒逼陈默直面"救一人vs揭真相"两难
  - 第22卷：发现妹妹死亡是系统"效率净化协议"的首次人体实验
  - 第35卷：选择用医者仁心弥补制度漏洞，而非单纯复仇
- **独立成长线**：
  - 第1-7卷：执着于"证明系统害人"，收集病历/尸检报告/监控录像
  - 第8-15卷：证据屡遭销毁，开始质疑"真相是否能改变什么"
  - 第16-22卷：发现妹妹死亡真相后崩溃，重新定义"正义"的含义
  - 第23-35卷：从"揭露者"转型为"修复者"，建立受害者家属互助网络
  - 第36-50卷：在新契约框架下推动"阴阳医疗援助"制度化
- **情绪功能**：提供"理性与情感的撕扯感"，平衡主角线的生存压迫，注入社会议题厚度
- **埋点配置**：短线12个（每卷1-2个）、中线8个、长线5个（妹妹死因/系统实验编号/老张身份/周然动机/互助网络雏形）
- **字数占比**：12%（约60-72万字）

### S2：骑手联盟线——"弱者的联合"

- **核心命题**：被系统异化的个体能否重建人与人之间的信任？
- **自驱目标**：建立骑手互助网络，对抗系统对个体的孤立与吞噬
- **关键角色**：老赵（前任骑手/联盟发起人）、阿杰（技术型骑手/加密通讯开发者）、小敏（女骑手/后勤支援）
- **与主线交叉点**：
  - 第4卷：陈默发现前任骑手遗物，获得联盟暗号
  - 第9卷：联盟首次集结，共享系统漏洞
  - 第14卷：揭露联盟中有一人是系统卧底
  - 第19卷：联盟沟通机制被破解，被迫转入更深层地下
  - 第28卷：联盟从"反抗组织"转型为"新契约协商代表"
  - 第42卷：联盟成员参与新契约签署仪式
- **独立成长线**：
  - 第1-9卷：零散幸存者各自求生，通过暗号试探性接触
  - 第10-19卷：建立信任→遭遇背叛→重建更稳固的信任机制
  - 第20-28卷：从"对抗系统"转向"理解系统"，内部出现路线分歧
  - 第29-42卷：统一立场，成为新契约的民间谈判方
  - 第43-50卷：联盟制度化，成为阴阳秩序的常设监督机构
- **情绪功能**：提供"群体共情与信任重建的温暖感"，对冲系统的冰冷理性
- **埋点配置**：短线15个、中线10个、长线4个（暗号起源/卧底身份/加密算法来源/联盟章程草案）
- **字数占比**：10%（约50-60万字）

### S3：亡魂群像线——"被遗忘的愿望"

- **核心命题**：当活人被当作鬼对待，谁才是真正的"亡灵"？
- **自驱目标**：每个亡魂都有未完成的愿望，系统截取这些愿望生成订单，亡魂自身渴望被"看见"而非被"送达"
- **关键角色**：七岁女孩朵朵（长寿面订单）、退休教师老周（最后一课订单）、独居老人王奶奶（陪伴订单）等单元角色
- **与主线交叉点**：
  - 第1卷：朵朵订单揭示"活人订单"真相
  - 第5卷：王奶奶订单触发主角价值观动摇
  - 第12卷：亡魂集体称呼陈默"摆渡人"
  - 第20卷：亡魂群体开始主动拒绝系统订单，要求"被倾听而非被完成"
  - 第32卷：亡魂代表参与新契约协商
  - 第45卷：新契约确立"愿望倾听"替代"愿望执行"
- **独立成长线**：
  - 第1-12卷：被动等待系统分配订单，个体愿望被工具化
  - 第13-20卷：部分亡魂觉醒，开始质疑"被送达"的意义
  - 第21-32卷：形成亡魂自治意识，推选代表表达集体诉求
  - 第33-45卷：从"被服务对象"转变为"契约参与方"
  - 第46-50卷：在新秩序中获得"被记住"而非"被解决"的位置
- **情绪功能**：提供"灵魂共鸣与社会痛点的具象化"，是全书情感厚度的基石
- **埋点配置**：短线20个（每单元1-2个）、中线6个、长线3个（亡魂觉醒触发条件/自治机制雏形/"被记住"的定义）
- **字数占比**：15%（约75-90万字）

### S4：医院暗线——"白色高墙内的灰色地带"

- **核心命题**：当医疗系统也被"效率至上"逻辑渗透，谁来守护生命的尊严？
- **自驱目标**：揭示医院内部与"阴阳闪送"系统的隐秘关联，以及医疗资源分配中的系统性不公
- **关键角色**：院长李德明（表面仁慈/实则与资本方合作）、护士长刘姐（底层医护的良心）、药剂师小吴（发现药物异常）
- **与主线交叉点**：
  - 第2卷：妹妹治疗费用异常波动，暗示医院与系统数据互通
  - 第7卷：林晚在医院档案室发现妹妹病历被篡改
  - 第13卷：刘姐偷偷保留原始病历副本交给林晚
  - 第22卷：揭露李德明与资本方签订"效率优化"合作协议
  - 第30卷：小吴发现系统通过药物供应链影响患者生死
  - 第38卷：医院内部改革派与外部联盟联手推动制度变革
- **独立成长线**：
  - 第1-13卷：医院作为"背景板"存在，暗线通过细节渗透
  - 第14-22卷：林晚调查深入，医院内部权力结构浮出水面
  - 第23-30卷：底层医护觉醒，形成内部抵抗力量
  - 第31-38卷：内外联动，推动医院去"效率化"改革
  - 第39-50卷：新契约框架下建立"人文医疗"评估体系
- **情绪功能**：提供"现实痛感的锚定"，防止灵异设定悬浮，强化社会批判力度
- **埋点配置**：短线10个、中线7个、长线4个（病历篡改痕迹/合作协议编号/药物异常批次/改革派名单）
- **字数占比**：8%（约40-48万字）

  - 第25卷：Zero试图协助陈默推翻现任调度员，但其方案仍是"更高效的控制"
  - 第32卷：陈默拒绝Zero，指出"换一个新神不是解决方案"
  - 第40卷：Zero接受被废弃的命运，留下"不要成为下一个我"的警告

  - 第41-50卷：Zero的警告被写入新契约的"防异化条款"
- **情绪功能**：提供"对'解决方案'本身的反思"，防止终局沦为简单的"换好人上位"

## 三、多线并行交织规则

### 3.1 单卷编排五原则

1. **主次分明**：每卷确定1条主线+1-2条重点支线，其余支线仅作点缀或伏笔
2. **节奏错峰**：多条支线的高潮章节不得集中在同一10章区间内
3. **情绪互补**：高压支线（如S1/S5）与温情支线（如S3/S8）交替编排
4. **信息分流**：不同支线的关键信息披露分散在不同单元，避免信息过载
5. **视角轮换**：连续3章不得全部使用同一支线角色视角

### 3.2 四类交叉点设计规范

| 交叉类型 | 定义 | 操作方式 | 示例 |
| :--- | :--- | :--- | :--- |
| **事件交汇** | 多条支线因同一事件产生交集 | 事件同时推动多条支线进展 | 第13卷"证据被毁"同时影响S1/S4/S6 |
| **角色交汇** | 不同支线角色在同一场景互动 | 通过对话/行动传递多条支线信息 | 第15卷林晚与陈默对峙，同时推进S1/S10 |
| **主题交汇** | 不同支线在同一卷探讨相同主题 | 通过并置/对比强化主题表达 | 第22卷S1/S5/S8共同探讨"真相的代价" |
| **埋点交汇** | 一条支线的埋点是另一条支线的回收 | 跨支线伏笔增强整体感 | S4的"药物异常"埋点是S5"资本操控"的回收 |

### 3.3 冲突解决优先级

当多条支线在同一卷争夺篇幅时，按以下优先级排序：
1. 主线纲阶段目标相关支线 > 其他支线
2. 情绪峰值卷的核心支线 > 过渡卷支线
3. 长线埋点回收支线 > 新埋伏笔支线
4. 角色成长关键节点支线 > 日常推进支线
5. 读者期待度高的支线（根据前期反馈调整）> 低期待支线

## 四、支线收束策略

### 4.1 三类收束方式时间表

| 收束类型 | 支线 | 收束卷次 | 收束方式 |
| :--- | :--- | :--- | :--- |
| **终局前收束** | S2联盟/S4医院/S5资本/S6舆论/S7前任 | 第42-45卷 | 在新契约签署前完成阶段性使命，转为新秩序组成部分 |
| **终局同步收束** | S1林晚/S3亡魂/S8小禾/S10家庭 | 第48-50卷 | 与主线终局同步完成，但保留开放性余韵 |
| **保持开放** | S9边界 | 第50卷仍开放 | 新问题浮现，暗示"秩序永远在路上" |

### 4.2 防烂尾检查清单

每条支线进入收束阶段前，逐项核对：

- [ ] 自驱目标是否已达成或明确转化为新形态？
- [ ] 独立成长线是否有完整的起承转合？
- [ ] 所有中线埋点是否已回收或明确标记为"开放"？
- [ ] 长线埋点是否在收束卷有至少一次呼应？
- [ ] 情绪功能是否在收束时达到峰值或完成转化？
- [ ] 收束方式是否符合题材禁忌（无机械降神/无强行圆满）？
- [ ] 收束后是否留有"余韵"而非"句号"？

### 5.2 六项禁忌检查表

- [ ] 支线角色是否沦为"工具人"？（检查：拿走主角，支线是否仍能独立推进？）
- [ ] 支线是否喧宾夺主？（检查：单卷支线字数是否超过主线？）
- [ ] 支线情绪是否与主线冲突？（检查：高压主线卷是否搭配了过重的支线？）
- [ ] 支线收束是否依赖主角"开挂"？（检查：收束动力是否来自支线自身逻辑？）
- [ ] 支线是否重复主线已表达的主题？（检查：是否有独立的情绪/认知增量？）
- [ ] 支线描写是否违反T1禁用词/最毒句式？（检查：逐段过筛）

### 5.3 六维质量验收标准

| 维度 | 合格标准 | 优秀标准 |
| :--- | :--- | :--- |
| 独立性 | 拿走主角仍能推进 | 支线本身可作为短篇独立成立 |
| 交织感 | 与主线有明确交叉点 | 交叉点产生1+1>2的叙事效果 |
| 情绪增量 | 提供主线没有的情绪类型 | 情绪与主线形成复调/对位 |
| 埋点效能 | 埋点按时回收 | 埋点回收时产生跨支线联动 |
| 反AI味 | 通过T1/T2检查 | 语言风格与主线统一且有辨识度 |
| 收束质量 | 无烂尾/无机械降神 | 收束后留有余韵，读者愿意回味 |
