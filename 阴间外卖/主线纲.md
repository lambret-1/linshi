# 《超时扣款，阴间催单》完整主线纲与创作工程蓝图

## 一、抓注意力版主线纲摘要

### 【3秒钩子】
外卖员为救妹妹拼命跑单，系统却把超时扣款改成扣阳寿。

### 【核心反差】
本该催命的阴间订单，竟是活人被遗忘的愿望。

### 【3个必看爽/虐点】
- 用命换钱补手术费（生存痛感）
- 盲送破局打脸质疑（技能爽感）
- 亡魂订单揭人间疮（灵魂共振）

### 【留客收尾】
当系统提示音变成父亲的声音，他该继续接单还是砸碎手机？

## 二、主线纲正文

外卖员陈默为凑齐妹妹的手术费，被迫绑定"阴阳闪送"系统。该系统将冥币按1:100汇率折算人民币，但每单附带致命规则：超时扣的不是钱，是阳寿；差评罚的不是款，是五感剥夺。核心冲突在于"生存刚需"与"非人代价"的极致撕扯——他越努力赚钱救人，就越深陷阴间秩序对人性的异化。前期以"接单-破局-获利"为爽点循环，中期目标从"攒钱"置换为"找回被系统吞噬的活人情感"，后期揭露系统实为阴间对阳间"效率至上"法则的反噬实验。结局走向为开放式升华：陈默拒绝成神或毁灭系统，而是以凡人之躯重写阴阳契约，让"送达"回归"守护"本质。全书卖点紧扣书名反差：用最底层的跑腿日常，解构最宏大的生死命题；每一笔扣款都是人性拷问，每一次催单都是命运倒计时。

## 三、前3章详细章纲示范

### 第1章：差评扣命（留人）
- **前100字钩子（颠覆设定+急速倒计时）**："您的订单已超时3秒，扣除阳寿72小时。"手机弹窗亮起时，陈默正把凉透的黄焖鸡塞进顾客手里。对方笑着道谢，他却盯着自己突然花白的鬓角，听见血管里传来沙漏碎裂的声响。
- **留人设计**：开篇即抛出"超时=扣命"的颠覆性规则，用"72小时"具象化死亡压力；顾客的道谢与主角的生理异变形成认知错位，制造"日常场景下的恐怖谷效应"。
- **情绪落点**：窒息感+荒诞感。
- **反AI味要点**：禁用"不禁""竟然"等词；用"凉透的黄焖鸡""花白的鬓角"等感官细节替代心理描写。

### 第2章：冥币到账（爽点）
- **爽点类型**：绝境翻盘+资源获取。陈默发现被扣的72小时阳寿因"准时送达"触发隐藏奖励翻倍返还，且冥币账户多出300元（折合人民币3万）。他立刻转账医院，妹妹手术费缺口补上1/5。
- **情绪拉扯**：期待落差（以为必死→意外获偿）+理智情感博弈（庆幸有钱→恐惧代价）。
- **反AI味要点**：避免"他心中大喜"等直白情绪词；用"手指悬在转账键上抖了三下才按下"等身体反应传递复杂心绪。

### 第3章：活人订单（反转）
- **反转手法（人设底色置换）**：新订单备注写着"请帮我给女儿送碗长寿面，她今天七岁生日"。陈默赶到地址，却发现是座废弃小学。他拨通订餐电话，接听的却是妹妹的主治医生："你妹妹刚才问我，哥哥是不是去给别的小朋友过生日了？"——所谓"阴间订单"，实为系统截取了活人被遗忘的愿望，而"鬼魂"正是那些被现实抛弃的活人。
- **反转内核**：颠覆"阴间=死人世界"的认知，将灵异悬疑锚定在社会痛点上。
- **反AI味要点**：医生台词不加任何语气修饰；废弃小学仅用两个画面呈现；避免解释性旁白。

## 四、无限循环结构说明

| 循环层级 | 单元构成 | 防重复机制 |
| :--- | :--- | :--- |
| **基础单元** | 3章=1个小闭环 | 每单元更换"冲突类型+情绪落点" |
| **卷级单元** | 30-50章=1个大闭环 | 每卷完成一次"目标置换+认知升级" |
| **跨卷钩子** | 每卷结尾埋长线伏笔 | 伏笔回收周期≥3卷 |

> **操作要点**：建立"素材库"分类管理冲突类型、情绪模式、反转手法，每写一卷前随机抽取组合，避免惯性写作。

## 五、主角认知档案：陈默

| 认知层级 | 初始状态 | 终局状态 |
| :--- | :--- | :--- |
| **世界观（难变）** | "钱能解决一切问题" | "有些东西比钱更值得守护" |
| **自我定位（难变）** | "我只是个跑腿的" | "我是连接阴阳的信使，但不是神" |
| **价值观（难变）** | "效率高于一切" | "送达的意义不在速度，在温度" |
| **能力/技能/环境（可变）** | 普通骑手体能+熟悉路线+城中村出租屋 | 可短暂沟通阴阳但拒绝永久异能；技能服务于理解他人；始终住在人间烟火处 |

- **真缺点**：过度责任强迫症。把所有订单当成"必须完成的使命"，甚至牺牲他人意愿强行"拯救"，前期常因"好心办坏事"引发新冲突。
- **成长弧光**：从"用命换钱的工具人"到"尊重生命节奏的守护者"。上三层变化缓慢且伴随痛苦反复，避免顿悟式成长。

## 六、核心配角/反派设定

### 林晚（急诊科医生）
- **自驱目标**：调查妹妹离奇死亡真相（与系统有关）
- **与主线交叉点**：第3章作为"活人订单"触发者登场；第7卷成为陈默的"人间锚点"；第15卷因证据被毁陷入绝望
- **独立成长线**：从执着"证明系统害人"到接受"有些真相无法用医学验证"

### "调度员"（系统化身）
- **自驱目标**：执行阴间"效率净化协议"，清除阳间"低效情感"
- **与主线交叉点**：全程以订单提示音、规则弹窗形式存在；第10卷具象化为陈默已故父亲形象；第18卷揭露其本质是阳间资本逻辑在阴间的投影
- **反派深度**：并非邪恶，而是"绝对理性"的极端化身，"无恶意的恶"比脸谱化反派更具压迫感

## 八、钩子分类规则与部署节奏表

### 8.1 钩子分类规则

| 钩子类型 | 核心功能 | 适用场景 | 单章上限 | 滥用预警线 |
| :--- | :--- | :--- | :--- | :--- |
| **认知错位** | 激发"为什么？"解谜欲 | 新规则/新角色/异常事件首次出现 | 1个 | 连续3章使用同类型错位 |
| **信息差A** | 制造"快打脸！"期待感 | 主角掌握关键信息，他人误解/轻视 | 1个 | 同一信息差拖延超5章未兑现 |
| **信息差B** | 引发"别踩进去！"焦虑感 | 主角即将踏入陷阱/误会 | 1个 | 连续2章叠加同类焦虑 |
| **急速倒计时** | 强化"来得及吗？"紧迫感 | 任务时限/生命威胁/机会窗口 | 1个 | 倒计时频繁失效或随意延长 |
| **悬念留白** | 开篇留人，制造认知缺口 | 章节开头/卷首 | 1个 | 留白超3章无进展 |
| **极度反差** | 打破预期，强化记忆点 | 角色登场/规则揭示/转折时刻 | 1个 | 反差沦为套路化震惊 |
| **矛盾前置** | 开局即冲突，跳过铺垫 | 新单元启动/节奏提速 | 1个 | 矛盾缺乏后续支撑 |
| **颠覆设定** | 重构世界观认知 | 卷级转折/真相揭露 | 每卷≤2次 | 颠覆无伏笔支撑 |
| **极致情绪** | 唤起共情，锚定情感基调 | 人物高光/悲剧时刻/关系突破 | 1个 | 情绪脱离情节独立存在 |

> **强度分级**：高（卷级转折/主线推进）、中（单元闭环/角色成长）、低（氛围营造/细节点缀）。高强度钩子必须搭配中线以上埋点。

### 8.2 钩子部署节奏表

| 位置 | 钩子类型偏好 | 三章循环中的功能 |
| :--- | :--- | :--- |

| **章中（40%-60%）** | 信息差A/B/认知错位 | 留人章：深化疑问；爽点章：积累期待；反转章：强化误导可信度 |
| **章尾（最后200字）** | 急速倒计时/信息差B/认知错位 | 留人章：抛出下章钩子；爽点章：预留新危机；反转章：揭示部分真相引向更深疑问 |
| **卷首** | 颠覆设定/极度反差+长线埋点 | 确立本卷核心冲突与情绪基调 |

## 九、埋点分级体系与管理工具

### 9.1 埋点分级体系

| 埋点级别 | 回收周期 | 埋设手法 | 回收验证标准 |
| :--- | :--- | :--- | :--- |
| **短线** | 1-3章 | 对话碎片/环境细节/角色微表情 | 回收时读者能立刻联想到埋点 |
| **中线** | 1卷内（30-50章） | 重复出现的意象/配角行为模式/规则例外 | 回收时产生"原来如此"的顿悟感 |
| **长线** | ≥3卷 | 世界观底层逻辑/角色前史/系统起源 | 回收时重构读者对故事的理解 |

> **埋设铁律**：短线必须附着当前情节；中线需≥3次变奏重现；长线初期必须伪装成普通细节。

## 十、防崩盘机制与健康度检查

| 风险类型 | 预防措施 | 检查节点 | 应急方案 |
| :--- | :--- | :--- | :--- |
| **埋点遗忘** | 每卷结束强制核对追踪表 | 卷末 | 延迟埋点降级处理或融入新情节 |
| **钩子疲劳** | 同类型钩子间隔≥3章；高强度后接低强度缓冲 | 每10章 | 切换钩子类型；用"呼吸章"调节 |
| **悬念通胀** | 高价值钩子必须绑定主线进展 | 每卷首 | 回收低价值悬念；合并同类钩子 |
| **回收烂尾** | 回收前重读埋点原文；确保逻辑自洽 | 回收前1章 | 补充过渡细节；调整回收方式 |

> **健康度指标**：短线回收率≥95%；中线延迟率≤10%；长线废弃率=0%；钩子类型分布均衡（单类型占比≤30%）。

## 十一、抓注意力规则前置检查清单

每次对外展示前必须逐项勾选：

- [ ] **3秒钩子**：包含"主角身份+最烦现状+极端事件"三要素？删除了主角名字、设定解释、形容词？
- [ ] **核心反差**：只保留1个反差？删除了世界观、人物关系、背景铺垫？
- [ ] **3个看点**：严格限定3个？每个≤15字且有具体画面？覆盖至少2种不同情绪类型？
- [ ] **留客收尾**：开放式疑问？删除了结局暗示、幸福承诺、总结性语句？
- [ ] **整体校验**：全文≤150字？无T1禁用词？读起来像人话而非文案模板？

> **执行铁律**：未通过全部勾选的内容禁止对外发布。

## 十二、题材禁忌与风格锚点

### 都市灵异/脑洞/悬疑题材禁忌
- ❌ 禁止"鬼魂万能化"：阴间力量必须有明确限制与代价
- ❌ 禁止"主角圣母化"：善意必须伴随后果
- ❌ 禁止"设定解释癖"：规则通过事件展现，不用旁白科普
- ❌ 禁止"现实脱节"：灵异元素必须扎根真实社会痛点
- ❌ 禁止"结局机械降神"：解决方案必须源于角色成长与前期伏笔

### 风格四字段锚定
- **冷冽**：叙述克制不煽情，用细节代替感叹
- **粗粝**：市井气+行业黑话+不完整句式
- **留白**：关键情绪不写透，给读者填补空间
- **体温**：冰冷规则中埋藏微小暖意

## 十三、反AI味执行细则

### T1禁用词替换表

| 禁用表达 | 替代方案 |
| :--- | :--- |
| "他感到一阵恐惧" | "后颈汗毛竖起，手机屏幕的光在瞳孔里缩成针尖" |
| "这个线索很重要" | "他把那张皱巴巴的小票叠成方块，塞进袜筒最深处" |
| "就在这时，他突然想起了……" | 用环境触发记忆："消毒水味钻进鼻腔，他摸口袋的动作顿住了" |
| "读者一定会好奇" | （删除）直接呈现异常细节 |

### 感官锚定法
每个钩子/埋点必须绑定≥1种非视觉感官：
- **听觉**：调度员提示音里的电流杂音、病房监护仪滴答间隔变化
- **触觉**：冥币纸币的湿冷黏腻、手机震动马达异常频率
- **嗅觉**：订单餐盒混着的檀香味、老旧楼道霉味中飘来的奶香
- **味觉**：紧张时嘴里泛起的铁锈味、亡魂递来的糖块化在舌根的苦涩回甘

### 通用禁令
- 禁止比喻/排比/感叹号
- 禁止"命运""人性""救赎"等大词
- 留客收尾仅用问号
- 所有内容必须通过"删掉形容词后仍成立"测试
