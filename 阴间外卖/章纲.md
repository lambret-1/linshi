
**第一部分：章纲标准化模板 + 五步拆解法**

# 《超时扣款，阴间催单》完整章纲体系

## 一、章纲标准化模板

每章章纲控制在100-200字，按以下七大模块填写：

### 1. 基础信息（必填）
- **章节编号**：第X卷·第Y章（全书第Z章）
- **单元定位**：留人章 / 爽点章 / 反转章 / 呼吸章 / 衔接章
- **字数目标**：2500-3000字（精确到百位）
- **视角角色**：本章主要叙事视角（陈默/林晚/其他）

### 2. 本章任务（必填）
- **主线任务**：本章推动主线什么进展（一句话，≤20字）
- **支线任务**：本章推进哪条支线到什么程度（无则填"无"）
- **角色任务**：本章哪个角色的认知/关系发生什么变化（无则填"无"）

> **常见错误**：任务写成"描写XX场景"→纠正：任务必须是"推动什么进展"，场景是手段不是目的。

### 3. 钩子配置（必填）
- **章首钩子**：[类型代码] + 具体内容概述（≤15字）
- **章中钩子**：[类型代码] + 位置（40%/50%/60%）+ 内容概述
- **章尾钩子**：[类型代码] + 指向下章什么悬念

> **类型代码速查**：CR=认知错位 / IA=信息差A / IB=信息差B / CD=急速倒计时 / SL=悬念留白 / EC=极度反差 / CF=矛盾前置 / DS=颠覆设定 / EE=极致情绪

### 4. 埋点配置（必填）
- **本章埋设**：[级别代码][编号] + 埋点内容（≤10字）
- **本章回收**：[级别代码][编号] + 回收方式（≤10字）
- **本章呼应**：对哪些长线埋点进行变奏重现（无则填"无"）

> **级别代码速查**：S=短线 / M=中线 / L=长线

### 5. 情绪设计（必填）
- **目标情绪**：读者读完本章应感受到什么（1-2个词）
- **情绪载体**：通过什么具体场景/动作/细节传递该情绪（≤20字）
- **情绪节奏**：本章情绪曲线（如"压抑→短暂释放→更深压抑"）

> **常见错误**：情绪写成"紧张刺激"→纠正：必须具体到"窒息感""荒诞感""苦涩的温暖"等可感知的情绪颗粒度。

### 6. 反AI味检查（选填，建议每章填写）
- **感官锚点**：本章绑定的非视觉感官（听觉/触觉/嗅觉/味觉，至少1种）
- **T1禁用词预警**：本章易触发的禁用词及替代方案
- **对话去书面化**：本章对话是否含口癖/打断/沉默/答非所问

### 7. 正文留白区（选填）
- **留给正文发挥的空间**：哪些细节/对话/环境描写不在章纲中限定，由正文写作时即兴生成
- **不可逾越的红线**：哪些内容在章纲阶段已锁定，正文不得更改

> **使用原则**：章纲锁定"结构+情绪+钩子+埋点"，正文发挥"语言+细节+节奏微调"。章纲是骨架，正文是血肉。

## 二、五步拆解法：从卷纲到章纲

### Step 1：卷纲确认
- 重读本卷卷纲，确认：阶段目标、核心冲突、情绪曲线四阶段、钩子密度、埋点重心
- 核对本卷在支线活跃度矩阵中的状态，确认本卷需推进的支线列表

### Step 2：单元划分
- 将本卷40章划分为13个三章单元（最后1章为衔接章）
- 按卷纲中的"单元分配原则"标注每个单元的功能定位（建立冲突/推进冲突/情绪峰值/收束）
- 检查变奏单元配额（≤5个），确认压缩/扩展/错位/嵌套/呼吸单元的分布

### Step 3：任务分解
- 将卷级目标分解为单元级任务，再将单元级任务分解为章级任务
- 每章任务必须满足："推动什么进展"而非"描写什么场景"
- 检查任务链的因果逻辑：上一章的结果是否是下一章的起因

### Step 4：钩子埋点预分配
- 根据卷纲中的钩子配置清单和埋点配置清单，将钩子/埋点预分配到具体章节
- 检查钩子类型分布均衡性（单类型占比≤30%）
- 检查埋点回收周期是否符合分级要求

### Step 5：章纲填写与校验
- 按标准化模板逐章填写
- 完成单章后执行"单章完成度检查清单"
- 完成一个单元后执行"单元级检查清单"
- 完成全卷后执行"卷级检查清单"

> **批次节奏建议**：每次撰写10章章纲（约3-4个单元），完成后暂停校验，避免疲劳导致的机械填写。

## 三、三章循环在章纲中的落地

### 3.1 留人章章纲要点

| 字段 | 要点 | 常见偏差 |
| :--- | :--- | :--- |
| 章首钩子 | 必须在前100字内呈现，优先用DS/EC/CF/SL/EE | 钩子延迟到200字后才出现 |
| 本章任务 | 建立本章核心疑问或冲突前提 | 任务过于模糊（如"展开情节"） |
| 情绪设计 | 以"好奇/焦虑/震惊"为主导情绪 | 情绪过于平淡（如"平静叙述"） |
| 章尾钩子 | 必须指向下章爽点章的期待感 | 章尾无钩子或钩子与下章脱节 |

### 3.2 爽点章章纲要点

| 字段 | 要点 | 常见偏差 |
| :--- | :--- | :--- |
| 章首钩子 | 预设打脸前提或期待积累 | 直接给爽点，缺乏铺垫 |
| 本章任务 | 兑现留人章建立的期待，同时预留新代价 | 爽点无代价，沦为纯爽文 |
| 情绪设计 | 以"痛快/欣慰/苦涩的满足"为主导情绪 | 情绪单一（只有爽没有复杂感） |
| 章尾钩子 | 预留新危机或认知错位，引向反转章 | 爽完就结束，无后续张力 |

### 3.3 反转章章纲要点

| 字段 | 要点 | 常见偏差 |
| :--- | :--- | :--- |
| 章首钩子 | 铺设误导表象或异常现象 | 反转过早暴露 |
| 本章任务 | 揭示部分真相，但引向更深疑问 | 反转后无新问题，故事停滞 |
| 情绪设计 | 以"震撼/困惑/灵魂触动"为主导情绪 | 反转只有智力游戏感，无情绪冲击 |
| 章尾钩子 | 开放式留白或跨单元悬念 | 反转后强行闭合，失去余韵 |

### 3.4 单元变奏调整

| 变奏类型 | 章纲调整方式 |
| :--- | :--- |
| 压缩单元 | 两章合并为一个章纲，任务密度加倍，钩子精简为章首+章尾 |
| 扩展单元 | 拆分为4-5个章纲，增加铺垫层章纲，情绪曲线细化 |
| 错位单元 | 爽点章纲在前，留人章纲在后，章首钩子改为"结果前置" |
| 嵌套单元 | 外层章纲包含内层章纲引用标记，内层章纲独立填写 |
| 呼吸单元 | 章纲任务改为"角色塑造/氛围营造/细节补充"，钩子降为低强度 |

## 四、支线嵌入章纲的方法

### 4.1 三级标注法

| 级别 | 标注格式 | 含义 | 字数占比 |
| :--- | :--- | :--- | :--- |
| **背景级** | [BG-SX] | 支线仅作为背景元素出现，不推进 | ≤5% |
| **推进级** | [AD-SX] | 支线在本章有实质性推进 | 10%-20% |
| **焦点级** | [FC-SX] | 支线是本章节点之一，与主线并行 | 20%-30% |

> **SX为支线编号**：S1=林晚/S2=联盟/S3=亡魂/S4=医院/S5=资本/S6=舆论/S7=前任调度员/S8=小禾/S9=边界/S10=家庭

### 4.2 嵌入位置规范

| 支线级别 | 推荐嵌入位置 | 禁止嵌入位置 |
| :--- | :--- | :--- |
| 背景级 | 环境描写/对话背景/角色回忆 | 章首钩子/章尾钩子/情绪峰值 |
| 推进级 | 章中段落/对话穿插/场景转换 | 章首前100字/反转揭示瞬间 |
| 焦点级 | 独立段落/专属单元/与主线交叉点 | 与主线高潮争夺同一章 |

### 4.3 防喧宾夺主检查清单

- [ ] 本章支线字数是否超过主线？
- [ ] 本章支线是否抢占了主线钩子位置？
- [ ] 本章支线情绪是否与主线情绪冲突？
- [ ] 本章支线推进是否依赖主角"开挂"？
- [ ] 本章支线是否重复主线已表达的信息？

## 五、钩子/埋点在章纲中的标注规范

### 5.1 钩子类型代码表

| 代码 | 类型 | 适用位置 | 强度 |
| :--- | :--- | :--- | :--- |
| CR | 认知错位 | 章中/章尾 | 中 |
| IA | 信息差A | 章中 | 中 |
| IB | 信息差B | 章中/章尾 | 中高 |
| CD | 急速倒计时 | 章首/章尾 | 高 |
| SL | 悬念留白 | 章首 | 高 |
| EC | 极度反差 | 章首 | 高 |
| CF | 矛盾前置 | 章首 | 高 |
| DS | 颠覆设定 | 章首/卷首 | 极高 |
| EE | 极致情绪 | 章首/情绪峰值 | 高 |

### 5.2 埋点级别代码表

| 代码 | 级别 | 回收周期 | 标注格式 |
| :--- | :--- | :--- | :--- |
| S | 短线 | 1-3章 | S[三位数编号]，如S001 |
| M | 中线 | 1卷内 | M[三位数编号]，如M007 |
| L | 长线 | ≥3卷 | L[三位数编号]，如L003 |

### 5.3 联动标注格式

当钩子与埋点存在绑定关系时，使用以下格式：
- `[CR-M007]`：认知错位钩子绑定中线埋点M007
- `[CD-S012]`：急速倒计时钩子绑定短线埋点S012
- `[DS-L003]`：颠覆设定钩子绑定长线埋点L003

> **标注铁律**：高强度钩子（DS/EE/CD/SL/EC/CF）必须绑定M或L级埋点；低强度钩子可绑定S级埋点或不绑定。

## 六、三层质量检查清单

### 6.1 单章完成度检查（每章完成后执行）

| 类别 | 检查项 |
| :--- | :--- |
| **基础信息** | □ 章节编号正确 □ 单元定位明确 □ 字数目标合理 □ 视角角色一致 |
| **本章任务** | □ 主线任务≤20字且可验证 □ 支线任务标注级别 □ 角色任务有变化 |
| **钩子配置** | □ 章首钩子在前100字 □ 钩子类型符合单元定位 □ 章尾钩子指向下章 □ 高强度钩子绑定埋点 |
| **埋点配置** | □ 埋设/回收/呼应三项完整 □ 编号连续无重复 □ 回收周期符合分级 |
| **情绪设计** | □ 目标情绪具体可感知 □ 情绪载体有画面 □ 情绪节奏有起伏 |
| **反AI味** | □ 至少1种非视觉感官 □ T1禁用词已替换 □ 对话去书面化 |
| **整体** | □ 总字数100-200字 □ 无解释性旁白 □ 读起来像工程文档而非散文 |

### 6.2 单元级检查（每单元完成后执行）

- [ ] 三章任务链因果逻辑是否自洽？
- [ ] 留人→爽点→反转的情绪曲线是否有起伏？
- [ ] 单元内钩子类型是否不重复？
- [ ] 单元内埋点是否有至少1个回收？
- [ ] 单元变奏是否符合配额（≤5个/卷）？

### 6.3 卷级检查（每卷完成后执行）

- [ ] 全卷章纲是否覆盖卷纲所有目标？
- [ ] 钩子类型分布是否均衡（单类型≤30%）？
- [ ] 埋点回收率是否达标（短线≥95%/中线延迟≤10%/长线废弃=0）？
- [ ] 支线嵌入是否符合活跃度矩阵？
- [ ] 全卷是否通过反AI味抽检（随机抽10章过筛）？

## 八、章纲与正文的衔接

### 8.1 确定项vs发挥项对照表

| 类别 | 章纲确定（正文不得更改） | 正文发挥（章纲不限定） |
| :--- | :--- | :--- |
| 结构 | 单元定位/任务链/钩子位置 | 段落划分/过渡方式 |
| 情绪 | 目标情绪/情绪载体/节奏曲线 | 具体修辞/句式长短 |
| 钩子 | 类型/位置/绑定埋点 | 具体措辞/呈现方式 |
| 埋点 | 编号/内容/回收方式 | 融入场景的自然度 |
| 角色 | 认知变化/决策逻辑 | 对话细节/微表情 |
| 支线 | 级别/推进程度 | 具体场景/互动方式 |
| 反AI味 | 感官锚点/T1替换 | 语言风格/节奏微调 |

### 8.2 8步正文写作流程

1. **重读章纲**：确认本章任务/钩子/埋点/情绪
2. **写章首100字**：严格按章纲钩子类型落地，写完即检查
3. **写主体段落**：按任务链推进，每写完一个段落回看章纲确认方向
4. **嵌入支线**：按标注级别在对应位置插入，写完检查字数占比
5. **写章尾200字**：严格按章纲钩子落地，确保指向下章
6. **反AI味过筛**：逐段检查T1禁用词/最毒句式/感官锚点
7. **情绪校验**：通读全文，确认目标情绪是否传达到位
8. **章纲修订**：若正文偏离章纲，记录原因并更新章纲（版本标记v1.1/v1.2）

### 8.3 章纲修订规则

| 修订类型 | 触发条件 | 操作方式 |
| :--- | :--- | :--- |
| 微调 | 正文发现更好的细节/对话 | 更新章纲"正文留白区"，不改结构 |
| 中调 | 正文发现任务链需调整 | 更新本章+下章章纲，标记v1.1 |
| 大调 | 正文发现卷级目标需修正 | 回溯卷纲，重新拆解受影响单元 |

> **版本管理建议**：每卷章纲保存为独立文件，修订时在文件名加版本号（如V1_ch001-040_v1.1.md）。
