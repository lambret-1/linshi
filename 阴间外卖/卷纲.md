## 二、前10卷详细卷纲示范

### 第1卷：差评扣命（1-40章）

- **阶段目标**：建立"超时=扣命"核心规则，完成主角从普通人到阴阳骑手的身份转变
- **核心冲突**：环境压力（阳寿扣除+妹妹手术费双重压迫）
- **情绪曲线**：
  - 铺垫（1-10章）：日常跑单+妹妹病情+系统绑定
  - 触发（11-20章）：首次超时扣命+冥币到账的残酷等价
  - 撕裂（21-30章）：发现"活人订单"真相，认知动摇
  - 释放（31-40章）：接受骑手身份，但质疑系统本质
- **钩子设计**：章首以"颠覆设定"为主；章中以"信息差B"制造焦虑；章尾以"急速倒计时"衔接下章
- **反转预埋**：[短]顾客手指冰凉→第3章回收；[中]系统界面褪色logo→第8卷回收；[长]"阴阳闪送"创始人线索→第16卷回收
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：第1章前100字必须出现"超时3秒扣阳寿72小时"；第3章废弃小学仅用"操场杂草没过膝盖""教室门牌歪斜挂着"两个画面

### 第2卷：五感赌局（41-80章）

- **阶段目标**：引入"差评=剥夺五感"规则，完成第一次目标置换
- **核心冲突**：价值错位（赚钱救妹妹vs保住感官完整性）
- **情绪曲线**：
  - 铺垫（41-50章）：首次差评失去味觉，吃饭如嚼蜡
  - 触发（51-60章）：为赚高额赏金主动接高危单，失明3天
  - 撕裂（61-70章）：盲送过程中靠听觉/触觉破局，却发现妹妹病情恶化
  - 释放（71-80章）：第50章目标置换完成——从"攒钱"转向"保住五感"
- **钩子设计**：章首以"矛盾前置"为主（感官剥夺的即时冲击）；章中以"认知错位"（失明反而感知到常人忽略的信息）；章尾以"信息差A"（主角掌握盲送技巧，他人不知）
- **反转预埋**：[短]失明期间听到的低频嗡鸣→第4卷回收（系统底层频率）；[中]味觉丧失后尝到的"苦味"→第5卷回收（亡魂食物的真实味道）
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：盲送章节禁用视觉描写，全程用听觉/触觉/嗅觉推进；失明恢复瞬间不用"重见光明"，用"路灯的光刺得眼眶发酸，他眯着眼数了三遍才确认是自家楼道"

### 第3卷：亡母遗言（81-120章）

- **阶段目标**：将生存压力升维至情感层面，完成第一个情绪峰值
- **核心冲突**：目标置换（纯粹求生→亲情羁绊）
- **情绪曲线**：
  - 铺垫（81-90章）：接到疑似亡母的订单，犹豫是否接单
  - 触发（91-100章）：为保听力放弃高额订单，却意外在寂静中听到亡母遗言
  - 撕裂（101-110章）：遗言内容与记忆矛盾，怀疑系统伪造
  - 释放（111-120章）：确认遗言真实，但意识到系统在用亲情操控自己
- **钩子设计**：章首以"极致情绪"为主（亲情与规则的撕扯）；章中以"信息差B"（读者知遗言可能为真，主角不确定）；章尾以"悬念留白"（遗言中隐藏的未解信息）
- **反转预埋**：[短]遗言中提到的"老地方"→第5卷回收；[中]亡母声音的频率特征→第10卷回收（与调度员声音重叠）；[长]遗言中"别信那个声音"→第18卷回收
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：亡母遗言不用煽情台词，用日常唠叨片段（"锅里留着粥""袜子破了自己补"）；听到遗言时的反应不用"泪流满面"，用"他蹲在路边，把脸埋进膝盖，肩膀没动，只有呼吸声变了调"

### 第4卷：骑手坟场（121-160章）

- **阶段目标**：将个体困境扩展至群体命运，揭示系统对骑手的系统性吞噬
- **核心冲突**：冲突连锁（个人生存→前任骑手的集体悲剧）
- **情绪曲线**：
  - 铺垫（121-130章）：发现前任骑手的遗物藏在出租屋夹层
  - 触发（131-140章）：遗物中的日记揭示"所有骑手最终都被系统吞噬"
  - 撕裂（141-150章）：试图联系前任骑手家属，却被系统警告"泄露规则=立即清零"
  - 释放（151-160章）：决定不再独自求生，开始暗中记录系统罪证
- **钩子设计**：章首以"悬念留白"为主（遗物中的异常细节）；章中以"认知错位"（日记内容与系统宣传完全相反）；章尾以"信息差B"（读者知系统监控，主角仍在冒险记录）
- **反转预埋**：[短]日记中提到的"安全屋"→第6卷回收；[中]前任骑手留下的暗号→第9卷回收（骑手联盟接头信号）；[长]日记最后一页被撕掉的内容→第16卷回收
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：日记内容不用完整摘录，用碎片化片段+主角阅读时的生理反应穿插；系统警告不用弹窗文字，用"手机震动频率突然变成心跳节奏，屏幕亮度自动调到最低，像有人在盯着他"

### 第5卷：一碗面的代价（161-200章）

- **阶段目标**：完成价值观第一次实质性动摇，衔接求生期与觉醒期
- **核心冲突**：价值错位（效率至上vs送达温度）
- **情绪曲线**：
  - 铺垫（161-170章）：接到"给独居老人送长寿面"订单，系统标注"低优先级"
  - 触发（171-180章）：为送这碗面耽误3单，被扣阳寿+罚款，但老人握着他的手说"谢谢你没让我一个人过生日"
  - 撕裂（181-190章）：系统惩罚加剧，妹妹手术费缺口扩大，质疑"温度是否值得代价"
  - 释放（191-200章）：确认"送达的意义不在速度，在温度"，但承认自己还没做到
- **钩子设计**：章首以"极度反差"为主（系统判定低价值vs人间高价值）；章中以"信息差A"（主角知道老人的故事，系统不知道）；章尾以"认知错位"（爽感伴随更大代价）
- **反转预埋**：[短]老人给的红包里夹着纸条→第7卷回收（林晚线索）；[中]"低优先级"订单的真实来源→第8卷回收（系统故意测试人性）；[长]老人说的"以前也有人给我送过面"→第17卷回收（与父亲有关）
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：老人握手不用"温暖的手掌"，用"指甲缝里有洗不掉的酱油渍，手背上的老年斑像地图，握力轻得像怕捏碎什么"；被罚后的挣扎不用"内心煎熬"，用"他把罚单揉成团塞进口袋，又掏出来展平，折痕处已经磨白了"
### 第6卷：好心办坏事（201-240章）

- **阶段目标**：触发主角真缺点"过度责任强迫症"，揭示善意可能造成伤害
- **核心冲突**：人设底色置换（善意→伤害）
- **情绪曲线**：
  - 铺垫（201-210章）：接到亡魂"完成遗愿"订单，亡魂恳求替自己向女儿道歉
  - 触发（211-220章）：陈默擅自找到亡魂女儿传达遗言，女儿崩溃大哭——她早已原谅父亲，陈默的"好心"反而撕开了刚愈合的伤口
  - 撕裂（221-230章）：系统判定"违规干预活人情感"，扣除大量阳寿；林晚指责陈默"你以为你在救人，其实你在满足自己的使命感"
  - 释放（231-240章）：承认自己的"拯救欲"本质是失控感的代偿，但仍未完全放下
- **钩子设计**：章首以"矛盾前置"为主（亡魂恳求vs系统警告）；章中以"信息差B"（读者知女儿已原谅，主角不知）；章尾以"极致情绪"（女儿的崩溃与主角的自责）
- **反转预埋**：[短]女儿哭诉中提到的"爸爸最后一次打电话"→第8卷回收；[中]亡魂订单的真实发起者→第12卷回收（并非亡魂本人）；[长]系统对"违规干预"的惩罚规则漏洞→第15卷回收
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：女儿崩溃不用"嚎啕大哭"，用"她盯着手机屏幕，嘴唇动了动没出声，眼泪砸在屏幕上把聊天记录洇成一片模糊"；林晚指责不用"愤怒的语气"，用"她把病历本摔在桌上，纸页散开，声音比平时低了半度"

### 第7卷：人间锚点（241-280章）

- **阶段目标**：确立林晚作为"人间锚点"的功能，建立主角与现实的稳定连接
- **核心冲突**：信息差错位（信任vs怀疑）
- **情绪曲线**：
  - 铺垫（241-250章）：林晚主动接触陈默，提供妹妹治疗的额外资源
  - 触发（251-260章）：林晚识破系统伪装成"医疗援助"的陷阱，帮陈默避开一次致命扣款
  - 撕裂（261-270章）：陈默怀疑林晚动机（是否与系统有关），两人信任危机
  - 释放（271-280章）：林晚坦白自己在调查妹妹离奇死亡真相，与陈默目标部分重合，达成有限同盟
- **钩子设计**：章首以"悬念留白"为主（林晚的真实目的）；章中以"信息差A"（林晚掌握系统医学证据，主角不知）；章尾以"认知错位"（信任建立的同时暴露更大疑点）
- **反转预埋**：[短]林晚提供的药物包装上的编号→第9卷回收；[中]林晚妹妹死亡时间与系统升级时间重合→第13卷回收；[长]林晚家族与"阴阳闪送"创始人的关联→第18卷回收
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：信任危机不用"互相猜忌"，用"他接过药瓶时指尖碰到她的手，两人都顿了一下，谁也没先收回手，也没多说一个字"；林晚坦白不用"深情倾诉"，用"她把一张泛黄的照片推过来，照片边缘被摩挲得发毛，上面的人和她长得像，但眼神更空"

### 第8卷：收割人性（281-320章）

- **阶段目标**：揭露系统利用主角"钱能解决一切"信念进行人性收割，完成世界观第一次动摇
- **核心冲突**：颠覆设定（系统不是工具，是人性收割机）
- **情绪曲线**：
  - 铺垫（281-290章）：发现系统奖励机制与主角"赚钱救妹"执念高度绑定
  - 触发（291-300章）：系统故意推送高额订单诱导主角冒险，同时放大妹妹病情焦虑；第300章目标置换完成——从"自救"转向"救其他骑手"
  - 撕裂（301-310章）：意识到自己越努力越被系统操控，陷入"不接单妹妹等死，接单就被收割"的两难
  - 释放（311-320章）：接受"钱不能解决一切"，但尚未找到替代方案
- **钩子设计**：章首以"颠覆设定"为主（系统奖励=人性陷阱）；章中以"信息差B"（读者知系统在操控，主角刚开始察觉）；章尾以"急速倒计时"（妹妹病情恶化+系统诱导双重压力）
- **反转预埋**：[短]系统推送订单的时间规律→第10卷回收；[中]"钱能解决一切"信念的来源→第17卷回收（父亲临终遗言）；[长]系统收割人性的底层算法→第16卷回收
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：系统诱导不用"邪恶的低语"，用"手机弹窗的字体比平时大了两号，颜色从蓝变成暖黄，像妈妈哄孩子吃饭时的语气"；两难挣扎不用"痛苦抉择"，用"他把手机扣在桌上，又翻过来看一眼，再扣下去，反复七次，屏幕指纹叠成了一片灰"

### 第9卷：集体抗罚（321-360章）

- **阶段目标**：建立骑手联盟雏形，将个体反抗升级为群体行动
- **核心冲突**：环境压力极限递增（系统对集体行动的镇压）
- **情绪曲线**：
  - 铺垫（321-330章）：通过前任骑手暗号联系到3名幸存骑手
  - 触发（331-340章）：骑手联盟首次集结，共享系统漏洞信息
  - 撕裂（341-350章）：系统检测到集体行为，对联盟成员实施"连坐惩罚"，一人违规全员扣阳寿
  - 释放（351-360章）：联盟未解散，转为地下运作，建立更隐蔽的沟通机制
- **钩子设计**：章首以"矛盾前置"为主（集结即遭镇压）；章中以"信息差A"（联盟掌握漏洞，系统未察觉）；章尾以"认知错位"（镇压反而强化了联盟凝聚力）
- **反转预埋**：[短]连坐惩罚中的"例外条款"→第11卷回收；[中]3名幸存骑手中有一人是系统卧底→第14卷回收；[长]联盟沟通机制的加密方式→第19卷回收（与阴阳契约重写有关）
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：集结场景不用"热血沸腾"，用"四个人坐在便利店角落，没人说话，只有吸管戳破塑封膜的声响，和冰柜压缩机嗡嗡的底噪"；连坐惩罚不用"残酷无情"，用"四个人的手机同时亮起，弹窗内容一模一样，连震动节奏都同步，像四颗心脏被同一只手捏住"

### 第10卷：父亲的声音（361-400章）

- **阶段目标**：调度员首次具象化，将系统对抗升维至父子关系层面，衔接觉醒期与对抗期
- **核心冲突**：人设底色置换（系统=父亲形象）
- **情绪曲线**：
  - 铺垫（361-370章）：系统提示音开始出现熟悉的咳嗽声（父亲生前习惯）
  - 触发（371-380章）：调度员首次以父亲形象出现在梦境/幻觉中，用父亲的语气下达指令
  - 撕裂（381-390章）：陈默无法分辨是系统伪装还是父亲亡灵，执行指令时手抖到握不住手机
  - 释放（391-400章）：确认是系统伪装，但承认自己对父亲的思念被系统精准利用
- **钩子设计**：章首以"极致情绪"为主（父亲声音的冲击）；章中以"信息差B"（读者知是系统伪装，主角不确定）；章尾以"悬念留白"（父亲形象消失后留下的异常数据）
- **反转预埋**：[短]父亲咳嗽声的频率→第14卷回收（与系统底层代码匹配）；[中]父亲形象出现的触发条件→第17卷回收（与主角情绪波动相关）；[长]父亲过劳死与系统创建的因果关系→第18卷回收
- **字数规划**：40章×2800字≈11.2万字
- **关键章纲提示**：父亲形象不用"慈祥的面容"，用"那张脸比他记忆里老了十岁，眼窝深陷，嘴角下垂，穿着去世那天的灰色夹克，袖口磨出了线头"；手抖不用"颤抖不已"，用"手机在掌心里滑了三次才握住，指节发白，指甲掐进塑料壳里留下月牙印"
## 三、卷间衔接设计

### 3.1 四种卷尾-卷首咬合机制

| 咬合类型 | 操作方式 | 适用场景 | 示例 |
| :--- | :--- | :--- | :--- |
| **悬念接力** | 卷尾抛出未解疑问，卷首前3章给出部分答案并引出新疑问 | 同阶段内卷间过渡 | 第1卷尾"褪色logo"→第2卷首"logo与某科技公司关联" |
| **情绪余震** | 卷尾情绪峰值的残留影响带入卷首，新冲突在余震中爆发 | 情绪峰值卷→下一卷 | 第3卷尾"亡母遗言"的悲伤→第4卷首"带着悲伤发现骑手坟场" |
| **角色交叉** | 卷尾配角行动线未完结，卷首从该配角视角开启新卷 | 配角关键节点卷 | 第6卷尾"林晚独自调查"→第7卷首"林晚视角接触陈默" |
| **规则迭代** | 卷尾揭示旧规则漏洞，卷首新规则上线填补漏洞但带来新问题 | 阶段过渡卷 | 第5卷尾"效率规则漏洞"→第6卷首"系统上线'情感干预'新规" |

### 3.2 三级跨卷钩子部署规范

| 钩子级别 | 埋设位置 | 回收周期 | 功能 | 部署密度 |
| :--- | :--- | :--- | :--- | :--- |
| **一级跨卷钩** | 每阶段末尾卷 | ≥3卷 | 驱动阶段转换 | 每阶段1个 |
| **二级跨卷钩** | 每卷卷尾 | 1-2卷 | 维持卷间追读欲 | 每卷1个 |
| **三级跨卷钩** | 单元循环章尾 | 3-10章 | 调节呼吸节奏 | 每单元1个 |

> **部署铁律**：一级跨卷钩必须绑定主线纲阶段目标；二级跨卷钩必须与本卷情绪峰值关联；三级跨卷钩仅用于调节节奏，不承担主线推进功能。

### 3.3 三处阶段过渡衔接策略

| 过渡节点 | 衔接策略 | 关键操作 |
| :--- | :--- | :--- |
| **求生期→觉醒期（第5卷→第6卷）** | "价值观裂缝"衔接 | 第5卷末确认"温度比效率重要"但未践行；第6卷首因"好心办坏事"被迫直面裂缝 |
| **觉醒期→对抗期（第10卷→第11卷）** | "身份撕裂"衔接 | 第10卷末确认调度员=父亲形象但未应对；第11卷首社会舆论将"摆渡人"标签公开化，逼迫主角回应 |
| **对抗期→重构期（第15卷→第16卷）** | "绝望重生"衔接 | 第15卷末林晚证据被毁+主角两难抉择；第16卷首在绝望中发现系统起源线索，从"破坏"转向"理解" |
## 四、三章循环在卷纲中的落地

### 4.1 单元分配原则

每卷约40章，包含13个"留人→爽点→反转"单元（最后1章为卷尾衔接章）。单元按卷内位置动态调整：

| 卷内位置 | 单元功能 | 留人章钩子偏好 | 爽点章类型 | 反转章手法 |
| :--- | :--- | :--- | :--- | :--- |
| 第1-3单元 | 建立本卷冲突+埋中线伏笔 | 颠覆设定/矛盾前置 | 技能成长/信息获取 | 逻辑误导 |
| 第4-7单元 | 推进冲突+情绪拉扯 | 信息差B/急速倒计时 | 打脸/资源获取 | 人设底色置换 |
| 第8-10单元 | 情绪峰值+目标置换 | 极致情绪/悬念留白 | 灵魂共鸣/群体共情 | 多重套娃 |
| 第11-13单元 | 收束本卷+埋跨卷钩子 | 认知错位/极度反差 | 代价型爽感 | 开放式留白 |

### 4.2 五种变奏策略（防机械重复）

| 变奏类型 | 操作方式 | 适用场景 |
| :--- | :--- | :--- |
| **压缩单元** | 2章完成"留人+爽点"或"爽点+反转" | 节奏提速/高潮密集段 |
| **扩展单元** | 4-5章展开一个单元，增加铺垫层 | 情绪峰值/重大反转 |
| **错位单元** | 爽点章在前，留人章在后（倒叙/插叙） | 回忆/揭秘/视角切换 |
| **嵌套单元** | 大单元内含小单元，外层反转包裹内层爽点 | 多重套娃反转 |
| **呼吸单元** | 整单元无强钩子/强爽点，纯日常/温情/细节 | 高潮后缓冲/角色塑造 |

> **使用配额**：每卷标准单元≥8个，变奏单元≤5个；呼吸单元每卷≤2个且不得连续出现。

### 4.3 单元与埋点绑定规则

| 单元位置 | 必绑埋点 | 可选埋点 |
| :--- | :--- | :--- |
| 第1单元 | 至少1个中线埋点 | 长线埋点（若本卷为长线起点） |
| 第4-7单元 | 至少1个短线埋点+1个中线埋点 | 跨卷钩子埋点 |
| 第8-10单元 | 至少1个中线埋点回收 | 长线埋点推进 |
| 第11-13单元 | 至少1个中线埋点回收+1个跨卷钩子 | 长线埋点更新状态 |
## 五、防重复检查：50卷不重复的组合策略

### 5.1 四维冲突轮换矩阵

每卷核心冲突从以下四维中选择1-2个主导，相邻卷不得重复同一维度：

| 维度 | 子类 | 可用卷次示例 |
| :--- | :--- | :--- |
| **价值错位** | 钱vs感官/效率vs温度/理性vs情感/个体vs集体 | 第2、5、8、14、22卷 |
| **环境压力** | 阳寿扣除/五感剥夺/连坐惩罚/舆论围剿/秩序崩塌 | 第1、4、9、11、19卷 |
| **目标置换** | 攒钱→保五感/自救→救他人/破坏→理解/战胜→共存 | 第3、6、10、15、20卷 |
| **人设底色** | 善意→伤害/系统→父亲/盟友→卧底/敌人→受害者 | 第7、10、12、17、24卷 |

> **轮换规则**：同一维度间隔≥3卷；同一子类间隔≥8卷。

### 5.2 八种情绪模式去重检查表

| 情绪模式 | 定义 | 每阶段上限 | 已用卷次 |
| :--- | :--- | :--- | :--- |
| 窒息压迫 | 生存压力下的无力感 | 2次 | 第1、4卷 |
| 残酷等价 | 用命换钱的痛感 | 2次 | 第2、8卷 |
| 亲情撕扯 | 血缘羁绊与规则冲突 | 2次 | 第3、10卷 |
| 群体共情 | 个体苦难引发集体共鸣 | 2次 | 第9、12卷 |
| 认知颠覆 | 固有信念被证伪的震撼 | 2次 | 第8、16卷 |
| 信任博弈 | 盟友/敌人身份的不确定性 | 2次 | 第7、14卷 |
| 绝望重生 | 谷底反弹的希望感 | 1次 | 第15卷 |
| 克制升华 | 放弃力量回归平凡的释然 | 1次 | 第20卷 |

> **检查节点**：每写完一卷，核对上表"已用卷次"栏，超限则调整下一卷情绪模式。

### 5.3 三种反转手法配额管理

| 反转手法 | 全书配额 | 每阶段配额 | 禁用场景 |
| :--- | :--- | :--- | :--- |
| 逻辑误导 | 20次 | 5次 | 不得用于核心主线转折 |
| 人设底色置换 | 15次 | 4次 | 不得对同一角色连续使用 |
| 多重套娃 | 10次 | 2次 | 仅限阶段过渡卷/情绪峰值卷 |

### 5.4 四类素材库随机抽取机制

建立四个素材库，每写一卷前从中各抽取1项组合：

| 素材库 | 内容示例 | 抽取规则 |
| :--- | :--- | :--- |
| **冲突事件库** | 盲送/连坐/证据销毁/舆论曝光/秩序失控 | 不得与上卷事件类型相同 |
| **感官细节库** | 电流杂音/湿冷黏腻/檀香味/铁锈味/消毒水味 | 每卷至少用2种未在上卷出现的感官 |
| **社会痛点库** | 外卖算法/医疗困境/孤独死/过劳/资本异化 | 每阶段覆盖≥3个不同痛点 |
| **角色互动库** | 沉默对峙/肢体语言/物品传递/环境共情/第三方转述 | 不得连续3卷使用相同互动模式 |
## 六、钩子/埋点对接规范

### 6.1 每卷钩子配置清单

| 钩子类型 | 每卷最低配置 | 每卷最高配置 | 必配位置 |
| :--- | :--- | :--- | :--- |
| 颠覆设定 | 1次 | 2次 | 卷首或阶段过渡卷 |
| 急速倒计时 | 3次 | 6次 | 每单元留人章或章尾 |
| 信息差B | 4次 | 8次 | 每单元章中或章尾 |
| 极致情绪 | 1次 | 3次 | 情绪峰值单元 |
| 认知错位 | 3次 | 6次 | 每单元反转章或卷尾 |

### 6.2 每卷埋点配置清单

| 埋点级别 | 每卷最低配置 | 每卷最高配置 | 必配位置 |
| :--- | :--- | :--- | :--- |
| 短线 | 8个 | 15个 | 每单元至少1个 |
| 中线 | 3个 | 6个 | 第1单元埋设+第11-13单元回收 |
| 长线 | 0-2个 | 3个 | 仅阶段起点卷/关键节点卷埋设 |

### 6.3 钩子-埋点联动检查表

每写完一卷，逐项核对：

- [ ] 每个高强度钩子是否绑定了中线以上埋点？
- [ ] 每个中线埋点是否在埋设后3章内有短线埋点呼应？
- [ ] 每个长线埋点是否在本卷有至少1次变奏重现？
- [ ] 卷尾跨卷钩子是否与下一卷首钩子形成咬合？
- [ ] 本卷钩子类型分布是否均衡（单类型占比≤30%）？
